# 📘 StudyTrail 学习轨迹

> 把散落各处的学习材料，变成一张自动维护的个人知识地图。

**在线体验（已部署）**：<https://xmy-lab.github.io/studytrail/>

StudyTrail 是一个轻量级 AI 学习伴侣。学生把任意学习材料（课堂笔记、文章、微信里收藏的干货、PDF 摘录……）粘贴进来，系统自动提取知识点、生成知识卡片并挂到个人主题地图上；每天通过**间隔重复 + 挖空测验**，针对最薄弱的主题安排复习。

## 它解决什么问题

学生的材料散落在五六个应用里——课件、录播课、微信群笔记、随手转发的链接——最终形不成连贯的知识全貌，也看不清哪里已掌握、哪里还薄弱。现有工具（Notion、印象笔记）是「收纳箱」：材料存进去了，但不会被复习。StudyTrail 补上从「存」到「学会」的最后一环。

## 核心功能（原型 v0.1）

| 功能 | 说明 |
|------|------|
| 🗺️ 知识地图 | 材料自动整理为知识卡片，按主题分组，每张卡片有待学习 / 学习中 / 已掌握状态 |
| ✨ 一键生成卡片 | 粘贴任意文本，本地「AI」抽取定义句和高频考点，自动生成卡片与主题 |
| 🔁 今日复习 | SM-2 简化版间隔重复算法调度到期卡片，挖空式提问 + 自评打分 |
| 📊 掌握度统计 | 各主题掌握度进度条，累计复习次数等指标 |

数据保存在浏览器 `localStorage`，无需注册登录。

## 快速开始

本项目是纯静态站点（HTML + CSS + 原生 JS），无需构建：

```bash
# 本地运行：任选其一
python -m http.server 8000     # 然后访问 http://localhost:8000
npx serve .
```

## 技术说明

- **零依赖纯前端**：单个 `index.html` + `style.css` + `app.js`，部署成本为零（GitHub Pages）。
- **卡片生成**：原型使用基于规则的本地「AI」——定义句式识别（`X 是……`）+ N-gram 关键词频次抽取。生产版将替换为 LLM API 调用，接口已隔离在 `app.js` 的 `generateCards()` 中。
- **间隔重复**：SM-2 简化版（ease 因子 + 间隔倍增），答错 10 分钟后重现，连续答对 2 次标记为已掌握。
